# Daily and Weekly Execution System

Back to [Roadmap Index](../README.md)

## Daily Minimum

- `30-60 min` learning
- `60-90 min` building
- `10 min` writing notes

## Ideal Deep-Work Day

- learn one concept from docs
- build the main feature
- debug and refactor
- publish notes or progress

## Weekly Review Questions

- what did I ship
- what did I understand poorly
- what took too long
- what failed repeatedly
- what is the next bottleneck to fix
