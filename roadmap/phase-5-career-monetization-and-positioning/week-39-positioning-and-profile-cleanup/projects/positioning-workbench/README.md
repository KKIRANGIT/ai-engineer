# Positioning Workbench

This project is a lightweight workspace for cleaning up technical positioning and profile consistency.

## What It Demonstrates

- project ranking by strategic fit
- profile consistency checks
- reusable headline, summary, and intro templates
- a repeatable way to translate project proof into positioning language

## Files

- `data/profile-data.json`: sample positioning inputs
- `data/projects.json`: sample project inventory with fit signals
- `templates/linkedin-headline-template.md`: headline structure
- `templates/linkedin-summary-template.md`: summary structure
- `templates/github-profile-template.md`: profile structure
- `templates/verbal-intro-template.md`: short intro structure
- `src/project-ranking.js`: ranking helpers for visible projects
- `src/positioning.js`: positioning statement and intro helpers
- `src/profile-audit.js`: consistency checks for profile messaging
- `tests/workbench.test.mjs`: ranking and consistency tests

## Suggested Study Order

1. inspect the sample profile data
2. read the template files
3. inspect the ranking and audit helpers
4. run the tests
5. replace the sample data with your own positioning inputs
