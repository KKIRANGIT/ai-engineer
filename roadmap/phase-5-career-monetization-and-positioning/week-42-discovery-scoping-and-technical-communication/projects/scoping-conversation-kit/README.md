# Scoping Conversation Kit

This project is a lightweight workspace for improving discovery and scoping quality.

## What It Demonstrates

- discovery question clustering
- scope boundary drafting
- risk register generation
- statement-of-work assembly

## Files

- `data/client-brief.json`: sample client and workflow brief
- `templates/discovery-call-template.md`: call structure
- `templates/ai-audit-template.md`: AI workflow audit structure
- `templates/statement-of-work-template.md`: compact SOW format
- `src/discovery.js`: discovery question helpers
- `src/risk-register.js`: risk extraction helper
- `src/scope-draft.js`: scope and SOW helpers
- `tests/scoping-kit.test.mjs`: discovery and scope checks

## Suggested Study Order

1. inspect the sample brief
2. read the templates
3. inspect the source helpers
4. run the tests
5. replace the sample brief with a real opportunity
