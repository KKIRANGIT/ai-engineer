# Career Asset Studio

This project is a lightweight workspace for turning project proof into reusable career assets.

## What It Demonstrates

- project evidence to resume bullet translation
- portfolio summary generation for different audiences
- proposal drafting from scope and risk inputs
- short and medium project walkthrough construction

## Files

- `data/project-evidence.json`: sample project proof inputs
- `data/opportunity-target.json`: sample role and buyer context
- `templates/resume-bullet-template.md`: bullet framing guide
- `templates/portfolio-summary-template.md`: portfolio summary structure
- `templates/proposal-template.md`: proposal structure
- `templates/project-walkthrough-template.md`: walkthrough outline
- `src/resume-builder.js`: resume bullet helpers
- `src/portfolio-summary.js`: portfolio summary helpers
- `src/proposal-builder.js`: proposal draft helpers
- `tests/asset-studio.test.mjs`: translation and reuse checks

## Suggested Study Order

1. inspect the sample evidence inputs
2. read the asset templates
3. inspect the source helpers
4. run the tests
5. replace the sample data with your own project proof
