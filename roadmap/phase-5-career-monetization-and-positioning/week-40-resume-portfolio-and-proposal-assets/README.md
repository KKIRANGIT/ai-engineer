# Week 40: Resume, Portfolio, and Proposal Assets

Back to [Phase 5](../README.md)

## Goal

Create a reusable asset pack that supports hiring conversations, freelance proposals, and project walkthroughs without forcing you to start from zero every time.

## Why This Week Matters

Strong people often lose opportunities because their assets are weak:

- resume does not reflect real strengths
- portfolio does not frame projects clearly
- proposals are generic
- project explanations are improvised

This week fixes that by converting your work into reusable communication tools.

## Week 40 Outcomes

By the end of this week, you should have:

- a role-focused resume
- stronger project summaries
- a portfolio that highlights value and tradeoffs
- a proposal template for client work
- a repeatable project walkthrough structure

## What To Learn and Prepare

## 1. Resume framing

A strong resume should communicate:

- what problems you can solve
- what kinds of systems you built
- what technical depth you can discuss

Do not make the resume a tool list. Make it an evidence summary.

## 2. Project bullet writing

Every strong project should become:

- 1-2 resume bullets
- one portfolio summary
- one interview story

## 3. Proposal structure

For freelance or consulting paths, prepare:

- project understanding
- scope
- approach
- assumptions
- risks
- next steps

## Execution Plan

Create:

- one primary resume
- one shorter or alternate version if needed for specific roles
- one project-summary template
- one proposal template
- one project walkthrough outline

## Deliverables

- updated resume
- portfolio project summaries
- proposal template
- project walkthrough script

## Exit Criteria

- you can explain your projects clearly and consistently
- your resume reflects your actual strengths
- you can respond to an opportunity without starting from scratch

## Common Mistakes To Avoid

- turning the resume into a keyword dump
- describing projects without user or business value
- writing proposals that sound identical for every client

## Expert Notes That Matter Here

### Assets should reduce response time

Good assets make it easier to apply, pitch, and respond with quality.

### Project framing is career leverage

A strong project description can change how the same work is perceived.

## Final Standard For This Week

The correct outcome is not "I made a resume."

The correct outcome is:

"I created a reusable set of hiring and client-facing assets that translate my technical work into clearer opportunities."
