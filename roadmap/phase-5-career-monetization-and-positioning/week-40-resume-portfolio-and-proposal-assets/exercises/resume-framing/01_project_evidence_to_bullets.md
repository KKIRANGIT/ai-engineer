# Exercise: Project Evidence To Resume Bullets

Choose two projects from Phases 3 or 4.

For each project, write:

- one outcome-focused bullet
- one architecture-focused bullet
- one tradeoff-focused interview note

Constraint:

- avoid generic verbs like "worked on" or "helped with"
- mention the user, system, or outcome where possible

Done means:

- each bullet could survive a follow-up question
- each bullet sounds different because the project evidence is different
