# Proof Content Studio

This project is a lightweight workspace for planning and evaluating proof-oriented technical content.

## What It Demonstrates

- content theme planning from project evidence
- proof-first post structure
- draft quality checks for specificity
- repurposing one artifact into multiple formats

## Files

- `data/content-assets.json`: sample project-driven content ideas
- `templates/build-log-template.md`: build-log structure
- `templates/architecture-post-template.md`: architecture post structure
- `templates/lesson-post-template.md`: lesson-focused structure
- `src/theme-planner.js`: theme selection helper
- `src/proof-check.js`: specificity and evidence helper
- `src/repurpose.js`: format repurposing helper
- `tests/proof-content-studio.test.mjs`: proof and repurposing checks

## Suggested Study Order

1. inspect the content assets
2. read the templates
3. inspect the source helpers
4. run the tests
5. replace the sample assets with your own project themes
