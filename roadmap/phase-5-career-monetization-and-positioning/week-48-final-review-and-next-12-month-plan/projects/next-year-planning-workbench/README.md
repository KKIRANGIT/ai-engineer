# Next-Year Planning Workbench

This project is a lightweight workspace for reviewing yearly signal and choosing a next-step direction.

## What It Demonstrates

- yearly review summarization
- path option comparison
- priority drafting for the next quarter
- planning metrics tied to direction

## Files

- `data/year-review.json`: sample yearly signal
- `templates/year-review-template.md`: review structure
- `templates/path-decision-template.md`: decision memo structure
- `templates/quarter-plan-template.md`: next-quarter plan structure
- `src/review-summary.js`: yearly signal helper
- `src/path-selection.js`: path comparison helper
- `src/quarter-plan.js`: next-quarter planning helper
- `tests/next-year-planning-workbench.test.mjs`: review and planning checks

## Suggested Study Order

1. inspect the sample yearly review
2. read the templates
3. inspect the source helpers
4. run the tests
5. replace the sample review with your own year signal
