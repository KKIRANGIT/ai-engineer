# Delivery Leverage Kit

This project is a lightweight workspace for converting repeated delivery work into reusable process assets.

## What It Demonstrates

- workflow stage design
- template and checklist prioritization
- reusable handoff framing
- leverage scoring for repeated work

## Files

- `data/delivery-process.json`: sample workflow and repeated tasks
- `templates/project-kickoff-template.md`: kickoff structure
- `templates/qa-checklist-template.md`: QA structure
- `templates/handoff-template.md`: handoff structure
- `src/workflow.js`: workflow stage helper
- `src/leverage-audit.js`: reuse scoring helper
- `src/checklist-builder.js`: checklist helper
- `tests/delivery-leverage-kit.test.mjs`: workflow and reuse checks

## Suggested Study Order

1. inspect the sample process
2. read the templates
3. inspect the source helpers
4. run the tests
5. replace the sample process with your own delivery workflow
