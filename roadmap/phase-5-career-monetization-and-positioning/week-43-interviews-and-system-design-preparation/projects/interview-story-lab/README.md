# Interview Story Lab

This project is a lightweight workspace for turning shipped systems into interview-ready stories.

## What It Demonstrates

- story compression
- tradeoff answer preparation
- end-to-end design explanation
- portfolio-backed technical storytelling

## Files

- `data/project-story.json`: sample project evidence
- `templates/intro-template.md`: self-intro structure
- `templates/project-walkthrough-template.md`: walkthrough structure
- `templates/design-answer-template.md`: design discussion structure
- `src/story-compression.js`: intro and walkthrough helpers
- `src/tradeoff-bank.js`: tradeoff answer helpers
- `src/design-outline.js`: design explanation helper
- `tests/interview-story-lab.test.mjs`: clarity and tradeoff checks

## Suggested Study Order

1. inspect the sample project story
2. read the templates
3. inspect the source helpers
4. run the tests
5. replace the sample story with your strongest project
