# Opportunity Pipeline Tracker

This project is a lightweight workspace for tracking opportunities and improving outreach quality.

## What It Demonstrates

- pipeline-stage tracking
- channel performance summaries
- template-based outreach personalization
- weekly outreach rhythm design

## Files

- `data/opportunities.json`: sample pipeline entries
- `data/weekly-target.json`: sample outreach targets
- `templates/linkedin-outreach-template.md`: short outreach template
- `templates/founder-outreach-template.md`: founder outreach structure
- `templates/follow-up-template.md`: follow-up structure
- `src/pipeline-metrics.js`: stage and channel metrics
- `src/personalization.js`: message customization helper
- `src/weekly-rhythm.js`: weekly target helper
- `tests/pipeline-tracker.test.mjs`: pipeline and rhythm checks

## Suggested Study Order

1. inspect the sample pipeline
2. read the templates
3. inspect the metrics and personalization helpers
4. run the tests
5. replace the sample opportunities with your real targets
