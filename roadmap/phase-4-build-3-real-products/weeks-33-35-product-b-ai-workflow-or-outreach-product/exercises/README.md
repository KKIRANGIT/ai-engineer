# Product B Exercises

These exercises are organized by week because the workflow product should be explainable from manual baseline to ROI story.

## Order

1. `week-33-workflow-analysis-and-decomposition/`
2. `week-34-build-the-workflow-engine/`
3. `week-35-quality-roi-and-product-story/`

## Done Standard

You are done with the exercise layer when you can explain:

- what the manual workflow looked like before the product
- why each automation step exists
- where human review still belongs
- what evidence supports the ROI story
