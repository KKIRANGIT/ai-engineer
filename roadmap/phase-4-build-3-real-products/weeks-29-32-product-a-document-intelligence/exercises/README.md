# Product A Exercises

These exercises are organized by week because Product A should feel like a disciplined product build, not a feature pile.

## Order

1. `week-29-scope-and-ingestion/`
2. `week-30-retrieval-and-grounding/`
3. `week-31-quality-and-trust/`
4. `week-32-product-polish-and-feedback/`

## Done Standard

You are done with the exercise layer when you can explain:

- why this niche is worth building for
- how ingestion and metadata affect trust
- where a failed answer came from
- what real feedback changed in the product
