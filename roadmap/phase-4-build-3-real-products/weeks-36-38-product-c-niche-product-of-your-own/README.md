# Weeks 36-38: Product C - Niche Product of Your Own

Back to [Phase 4](../README.md)

## Goal

Choose one domain you understand and build a product around a painful, repeated workflow.

## Selection Filter

- painful
- repetitive
- expensive when done manually
- frequent enough to justify software
- narrow enough for one person to ship

## Good Directions

- exam-specific AI tutor
- clinic note summarizer
- contract clause reviewer
- internal knowledge assistant
- recruiting workflow assistant

## Deliverables

- live demo if feasible
- real or realistic usage flow
- cost estimate
- case study with next-step roadmap
