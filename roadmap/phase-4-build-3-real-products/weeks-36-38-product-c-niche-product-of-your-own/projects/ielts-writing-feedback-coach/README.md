# IELTS Writing Feedback Coach

This project is a niche-specific product for IELTS Writing Task 2 feedback.

## What It Demonstrates

- niche-specific product framing
- rubric-shaped scoring logic
- structured feedback output
- focused improvement recommendations
- simple cost and pricing reasoning

## Files

- `data/submissions/`: representative student essays
- `docs/product-brief.md`: niche, user, and workflow framing
- `docs/pricing-thought-experiment.md`: pricing and monetization notes
- `docs/next-step-roadmap.md`: what to build next if the niche signal is strong
- `src/load-submissions.js`: sample submission loading
- `src/rubric.js`: simple rubric scoring heuristics
- `src/feedback.js`: structured feedback generation
- `src/study-plan.js`: next-step recommendation builder
- `src/cost-model.js`: rough per-session cost and margin helpers
- `tests/coach.test.mjs`: workflow, feedback, and cost tests

## Suggested Study Order

1. read the product brief
2. inspect the representative submissions
3. inspect the rubric and feedback modules
4. inspect the cost model and next-step roadmap
5. run the tests
6. adapt the product brief to a niche you personally want to explore
