# Product C Exercises

These exercises are organized by week because Product C should prove strategic judgment, not only implementation effort.

## Order

1. `week-36-problem-discovery-and-product-framing/`
2. `week-37-product-build/`
3. `week-38-validation-iteration-and-strategic-review/`

## Done Standard

You are done with the exercise layer when you can explain:

- why this niche is better than the obvious alternatives you rejected
- what the minimum credible workflow is
- what validation signal matters most
- whether the product deserves deeper investment
