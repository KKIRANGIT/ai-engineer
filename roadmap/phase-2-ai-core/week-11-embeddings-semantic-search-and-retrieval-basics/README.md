# Week 11: Embeddings, Semantic Search, and Retrieval Basics

Back to [Phase 2](../README.md)

## Goal

Understand how semantic retrieval works before building a full RAG system.

## Learn

- embeddings and vector similarity
- metadata filtering
- semantic vs keyword vs hybrid search
- hosted retrieval vs self-managed vector stores
- chunking basics

## Build

- index 100-500 documents
- search them semantically
- add metadata filters
- compare hosted retrieval with `pgvector`

## Deliverables

- retrieval prototype
- markdown or notebook comparing both approaches

## Exit Criteria

- you can explain what retrieval is doing under the hood
