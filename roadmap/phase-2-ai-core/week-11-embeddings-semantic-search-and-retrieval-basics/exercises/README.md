# Week 11 Exercises

Back to [Week 11](../README.md)

## Purpose

These exercises are designed to make retrieval mechanics explicit:

- why similar items cluster together
- how chunking changes retrievable units
- why filters matter
- how keyword, semantic, and hybrid search differ

The goal is not to memorize retrieval vocabulary. The goal is to develop retrieval judgment.

## Exercise Groups

### `embedding-intuition/`

Practical intuition for semantic closeness and vector-style reasoning.

### `chunking/`

Chunk boundary, overlap, and context tradeoffs.

### `filtering-and-ranking/`

Why metadata filters and scope control matter.

### `search-modes/`

Keyword, semantic, and hybrid retrieval comparison.

## How To Use These Exercises

Recommended order:

1. embedding intuition
2. chunking
3. filtering and ranking
4. search modes

For each script:

1. read the docstring
2. run the file
3. inspect the output
4. change one value and re-run it
5. explain what changed and why
