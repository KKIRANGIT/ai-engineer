# Week 12: RAG Done Properly

Back to [Phase 2](../README.md)

## Goal

Build a grounded document assistant that is useful beyond demo quality.

## Learn

- chunk sizing and overlap tradeoffs
- metadata strategy
- query rewriting
- reranking basics
- context packing
- citations and source display
- retrieval failure modes

## Build

- PDF or multi-document Q&A assistant
- upload flow
- retrieval debug view
- grounded answers with citations

## Deliverables

- live or local app
- 20-question grounded test set

## Exit Criteria

- the app answers from provided sources and shows where the answer came from
