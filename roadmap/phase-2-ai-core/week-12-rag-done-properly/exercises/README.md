# Week 12 Exercises

Back to [Week 12](../README.md)

## Purpose

These exercises are designed to make the stages of RAG explicit:

- pipeline flow
- query rewriting
- context packing
- failure categories

The goal is not to memorize a framework. The goal is to understand where grounded QA succeeds or fails.

## Exercise Groups

### `pipeline-thinking/`

See the RAG flow as a staged system.

### `query-rewriting/`

Practice turning user questions into better retrieval queries.

### `context-packing/`

Practice deciding what retrieved evidence should actually be shown to the model.

### `failure-analysis/`

Practice naming RAG failures by stage rather than blaming "the model."

## How To Use These Exercises

Recommended order:

1. pipeline thinking
2. query rewriting
3. context packing
4. failure analysis

For each file:

1. read the docstring
2. run it
3. inspect the output
4. compare the ideas to the project code
