# Week 12 Study Plan

Back to [Week 12](../README.md)

## Objective

Use this week to turn retrieval into a grounded application rather than a search demo.

The main success condition is not:

"The system answered from documents once."

It is:

- I can inspect what was retrieved
- I can explain how context was packed
- I can show where the answer came from
- I can categorize failures by stage

## Suggested Order

### Day 1

- read the Week 12 README
- complete the pipeline-thinking exercise
- map the stages to the project structure

### Day 2

- complete the query-rewriting exercise
- inspect how rewriting changes retrieval results

### Day 3

- complete the context-packing exercise
- inspect the context builder in the project

### Day 4

- inspect the answer generator
- understand how chunk citations are attached to the response

### Day 5

- run the project in answer mode and debug mode
- compare what the user sees with what the debug view shows

### Day 6

- complete the failure-analysis exercise
- run the evaluation set and inspect any misses

### Day 7

- read the grounded UX note
- write your own explanation of how retrieval trust is built in the project

## Minimum Success Definition

You should not leave this week saying:

"I built RAG."

You should leave saying:

"I understand how a grounded retrieval-backed assistant retrieves, packs, answers, cites, and fails."
