# Week 14 Exercises

Back to [Week 14 README](../README.md)

## Purpose

These exercises isolate the orchestration concepts before you study the larger project.

The point is to become fluent in:

- recognizing workflow vs agent patterns
- reading simple plan-act-observe loops
- thinking about state and retries
- understanding framework positioning

## Exercise Order

Work through these folders in order:

1. `workflow-vs-agent/`
2. `react-and-planner/`
3. `state-and-retries/`
4. `framework-positioning/`

## How To Use The Exercises

For each file:

1. run it
2. read the printed explanation
3. change one behavior or threshold
4. explain what that change did to control or complexity

Do not move to the main project until the orchestration patterns feel concrete instead of abstract.
