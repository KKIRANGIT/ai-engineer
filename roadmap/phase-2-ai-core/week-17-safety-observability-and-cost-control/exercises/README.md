# Week 17 Exercises

Back to [Week 17 README](../README.md)

## Purpose

These exercises isolate the core hardening concepts before you study the larger project.

The point is to become fluent in:

- mapping trust boundaries
- spotting injection-like text
- reasoning about retries and traces
- estimating request cost and budget risk

## Exercise Order

Work through these folders in order:

1. `trust-boundaries/`
2. `prompt-injection-and-guardrails/`
3. `observability-and-retries/`
4. `cost-and-budget-controls/`

## How To Use The Exercises

For each file:

1. run it
2. read the output
3. explain what boundary or control it is demonstrating
4. change one threshold or rule and describe the effect
