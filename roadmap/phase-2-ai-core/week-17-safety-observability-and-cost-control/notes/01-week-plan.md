# Week 17 Study Plan

Back to [Week 17 README](../README.md)

## Main Objective

By the end of this week, you should be able to reason about an AI system as something you can inspect, constrain, and cost.

## Suggested Flow

### Day 1

- read the Week 17 README
- run the trust-boundary exercises
- write down which inputs are trusted and untrusted

### Day 2

- run the guardrail exercises
- explain how suspicious text can influence a model

### Day 3

- run the observability exercises
- explain what trace fields matter most

### Day 4

- run the project on a normal request
- inspect the trace and retry behavior

### Day 5

- run the project on a suspicious request
- inspect the safety outcome and cost estimate

### Day 6

- read the failure-mode checklist
- write your own list of weak points

### Day 7

- review the notes
- summarize the main remaining risks and what you would harden next
