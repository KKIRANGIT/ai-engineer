# Week 17: Safety, Observability, and Cost Control

Back to [Phase 2](../README.md)

## Goal

Learn the production concerns that separate real systems from demos.

## Learn

- prompt injection basics
- tool abuse risks
- output validation
- token usage accounting
- rate limits and retries
- cost per user and cost per request
- tracing and logging

## Build

- add observability and cost tracking to an existing app
- add retries, timeout handling, and guardrails
- document known failure modes

## Deliverables

- cost estimate worksheet
- failure mode checklist

## Exit Criteria

- you can answer what a successful request costs and how failures are handled
