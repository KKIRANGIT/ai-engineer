# Week 16 Exercises

Back to [Week 16 README](../README.md)

## Purpose

These exercises isolate the key multimodal and realtime ideas before you study the larger project.

The point is to become fluent in:

- thinking in modality transitions
- understanding voice pipeline tradeoffs
- classifying vision tasks
- reasoning about event flow and streaming UX

## Exercise Order

Work through these folders in order:

1. `multimodal-mental-model/`
2. `voice-and-audio-pipelines/`
3. `vision-workflows/`
4. `streaming-and-sessions/`

## How To Use The Exercises

For each file:

1. run it
2. read the output
3. explain the architecture choice it is describing
4. change one design variable and describe what tradeoff changed
