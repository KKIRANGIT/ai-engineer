# Week 16 Study Plan

Back to [Week 16 README](../README.md)

## Main Objective

By the end of this week, you should be able to reason about multimodal and realtime systems as system designs, not just model features.

## Suggested Flow

### Day 1

- read the Week 16 README
- run the multimodal mental model exercises
- write down the modality transitions in your own words

### Day 2

- run the voice and audio exercises
- explain when you would prefer a chained pipeline

### Day 3

- run the vision exercises
- identify whether a task is extraction, classification, or open reasoning

### Day 4

- run the streaming and session exercises
- explain the event flow to yourself

### Day 5

- run the project in text-only mode
- run the same case in multimodal mode
- compare what changed

### Day 6

- run the session mode
- inspect the streaming chunks and session trace

### Day 7

- read the notes
- write a short architecture summary and latency note
