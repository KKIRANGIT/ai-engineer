# Week 18 Exercises

Back to [Week 18 README](../README.md)

## Purpose

These exercises isolate the milestone product thinking before you study the full capstone project.

The point is to become fluent in:

- scoping a serious AI use case
- choosing the right architecture pattern
- designing retrieval and structured outputs together
- making quality and case-study value visible

## Exercise Order

Work through these folders in order:

1. `project-scope-and-pattern-selection/`
2. `retrieval-and-structured-output-design/`
3. `evaluation-and-quality-review/`
4. `observability-and-case-study-thinking/`

## How To Use The Exercises

For each file:

1. run it
2. read the output
3. explain the decision or tradeoff it is highlighting
4. relate that idea back to the support-ops copilot project
