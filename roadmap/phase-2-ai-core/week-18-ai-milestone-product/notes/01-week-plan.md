## Main Objective

By the end of this week, you should have one integrated AI product you can explain credibly.

## Suggested Flow

### Day 1

- read the Week 18 README
- run the scope and pattern-selection exercises
- write down why the chosen architecture is not overbuilt

### Day 2

- run the retrieval and structured-output exercises
- inspect how the output contract helps the workflow

### Day 3

- read the project README
- run one ticket analysis
- inspect retrieved sources and structured output

### Day 4

- run a second ticket
- inspect SLA and escalation decisions
- inspect the trace

### Day 5

- run the evaluation command
- inspect failures and compare cases

### Day 6

- read the case-study checklist
- write your own short milestone summary

### Day 7

- review the project end to end
- make sure you can explain the architecture and tradeoffs clearly
