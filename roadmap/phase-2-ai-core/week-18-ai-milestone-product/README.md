# Week 18: AI Milestone Product

Back to [Phase 2](../README.md)

## Goal

Ship one serious AI application you can use in interviews or client conversations.

## Suggested Ideas

- document intelligence assistant
- meeting summarizer with action items
- AI research copilot
- support knowledge assistant

## Required Features

- clean UX
- structured outputs where needed
- source grounding
- logging
- usage limits
- basic eval set

## Deliverables

- live app
- public repo
- case study

## Exit Criteria

- you have one credible AI product, not just experiments
