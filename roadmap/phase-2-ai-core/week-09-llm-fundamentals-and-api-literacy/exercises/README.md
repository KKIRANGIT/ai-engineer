# Week 09 Exercises

Back to [Week 09](../README.md)

## Purpose

These exercises are designed to make the invisible parts of LLM integrations visible:

- context layers
- payload shape
- provider differences
- cost and latency thinking
- state-handling choices

The goal is not to memorize docs. The goal is to build a mental model that survives beyond sample code.

## Exercise Groups

### `concepts/`

Foundational mental models for context layers, token usage, latency, and cost.

### `payloads/`

Sample OpenAI and Anthropic request/response structures so you can see what each interface actually looks like.

### `state-and-debugging/`

Exercises for multi-turn planning, observability, and failure analysis.

## How To Use These Exercises

Recommended order:

1. concepts
2. payloads
3. state and debugging

For each script:

1. read the docstring
2. run it
3. inspect the printed structure
4. change values and re-run it
5. explain what changed and why
