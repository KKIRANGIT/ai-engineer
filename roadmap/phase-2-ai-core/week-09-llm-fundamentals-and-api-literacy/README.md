# Week 09: LLM Fundamentals and API Literacy

Back to [Phase 2](../README.md)

## Goal

Understand models as systems with costs, constraints, and tradeoffs.

## Learn

- tokens, latency, context windows, and cost
- system or developer instructions vs user input
- model family tradeoffs
- sampling basics
- prompt-injection awareness
- OpenAI Responses API
- Anthropic Messages API

## Build

- CLI chat app for OpenAI
- CLI chat app for Anthropic
- side-by-side comparison prompts across models

## Deliverables

- comparison notes on output quality, latency, and cost
- simple reusable API wrappers

## Exit Criteria

- you can choose a model intentionally instead of randomly
