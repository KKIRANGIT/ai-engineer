# Week 10: Prompt Engineering and Structured Outputs

Back to [Phase 2](../README.md)

## Goal

Produce reliable outputs that can power application logic.

## Learn

- clear instruction writing
- few-shot examples
- decomposition and constraint setting
- role framing
- XML or tagged organization when useful
- JSON-schema based structured outputs
- validation and refusal handling

## Build

- prompt template library
- structured extraction tool
- prompt regression set with 15-20 test inputs

## Deliverables

- folder of prompts, schemas, and expected outputs
- notes on common failure patterns

## Exit Criteria

- your outputs are stable enough to be consumed by code
