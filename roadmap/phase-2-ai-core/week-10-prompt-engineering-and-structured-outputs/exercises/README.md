# Week 10 Exercises

Back to [Week 10](../README.md)

## Purpose

These exercises are designed to improve prompt quality through deliberate thinking instead of trial-and-error guessing.

The goal is not to produce the cleverest wording. The goal is to understand:

- what the task really is
- how the prompt expresses that task
- what output the application needs
- where failures should be expected

## Exercise Groups

### `prompt-clarity/`

Practice rewriting vague tasks into precise instructions.

### `decomposition-and-examples/`

Practice splitting tasks and deciding when examples help.

### `prompt-organization/`

Practice structuring longer prompts with sections and XML-like tags.

### `structured-output-thinking/`

Practice designing schemas, handling refusals, and validating outputs.

## How To Use These Exercises

Recommended order:

1. prompt clarity
2. decomposition and examples
3. prompt organization
4. structured output thinking

For each file:

1. read the prompt scenario
2. run the script
3. inspect the suggested structure
4. rewrite one example in your own words
