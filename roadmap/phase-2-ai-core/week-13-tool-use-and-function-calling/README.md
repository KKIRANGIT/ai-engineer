# Week 13: Tool Use and Function Calling

Back to [Phase 2](../README.md)

## Goal

Make models act through software, not only generate text.

## Learn

- function schemas
- tool selection
- tool-result loops
- validation
- client tools vs hosted tools
- execution safety basics

## Build

- research assistant with at least three tools
- tool logging for every call and result
- deterministic wrappers around tool execution

## Deliverables

- tool-enabled demo
- logs or traces showing the full loop

## Exit Criteria

- you can build a reliable tool layer around a model
