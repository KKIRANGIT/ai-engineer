# Week 15 Exercises

Back to [Week 15 README](../README.md)

## Purpose

These exercises isolate the mechanics of evaluation before you study the larger project.

The point is to become fluent in:

- defining measurable success criteria
- creating representative test cases
- building graders
- reasoning about failure patterns
- deciding which optimization lever to use next

## Exercise Order

Work through these folders in order:

1. `success-criteria/`
2. `dataset-design/`
3. `graders-and-regressions/`
4. `fine-tuning-decisions/`

## How To Use The Exercises

For each file:

1. run it
2. read the output
3. explain what is being measured
4. change one threshold or rule and observe what it changes

Do not jump to fine-tuning decisions until the evaluation logic itself feels clear.
