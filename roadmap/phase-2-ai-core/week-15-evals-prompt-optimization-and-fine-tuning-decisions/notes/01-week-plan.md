# Week 15 Study Plan

Back to [Week 15 README](../README.md)

## Main Objective

By the end of this week, you should be able to explain improvement with evidence, not with vague impressions.

## Suggested Flow

### Day 1

- read the Week 15 README
- run the success-criteria exercises
- write down what "good" means for the task

### Day 2

- run the dataset-design exercises
- review why easy-only cases create false confidence

### Day 3

- run the baseline system in the project
- inspect the case-level failures

### Day 4

- run `prompt_v2`
- compare what improved and what did not

### Day 5

- run `retrieval_v1`
- compare prompt fixes versus knowledge fixes

### Day 6

- run the decision memo
- explain what the remaining failures suggest

### Day 7

- read the notes
- write your own short optimization report

## Review Questions

- What exactly is being measured?
- Which cases are most representative of production risk?
- Which failures look like prompt issues?
- Which failures look like knowledge or retrieval issues?
- What evidence would make fine-tuning justified?
