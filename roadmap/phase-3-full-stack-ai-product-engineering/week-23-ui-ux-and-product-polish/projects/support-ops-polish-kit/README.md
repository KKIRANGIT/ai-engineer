# Support Ops Polish Kit

This project is a lightweight preview kit for improving product communication in a support operations interface.

## What It Demonstrates

- clearer empty, loading, and in-progress states
- better next-step guidance for first-time users
- AI trust and latency messaging
- a small visual shell you can inspect without a heavy toolchain

## Files

- `preview.html`: a simple state-preview page
- `src/styles.css`: layout and state styling
- `src/ui-copy.js`: user-facing copy helpers
- `src/state-models.js`: state-to-guidance mapping helpers
- `tests/polish-kit.test.mjs`: behavioral tests for guidance copy

## Suggested Study Order

1. open the preview file in a browser
2. inspect the copy helpers
3. inspect the state mapping helpers
4. run the tests
5. adapt the copy structure for your own product flow
