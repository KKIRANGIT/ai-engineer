# Week 23: UI UX and Product Polish

Back to [Phase 3](../README.md)

## Goal

Move from functional developer UI to credible product UI.

## Learn

- information hierarchy
- loading, empty, and error states
- responsive design
- basic motion and feedback
- clear messaging around AI latency and uncertainty

## Build

- redesign one earlier app
- improve onboarding
- refine visual hierarchy and interaction states

## Deliverables

- before-and-after screenshots
- notes explaining the product improvements

## Exit Criteria

- the app feels intentional rather than assembled from defaults
