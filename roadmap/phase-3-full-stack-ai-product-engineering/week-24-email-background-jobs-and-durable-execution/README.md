# Week 24: Email, Background Jobs, and Durable Execution

## Goal

Handle long-running AI work correctly instead of blocking web requests.

## Learn

- event-driven flows
- queue mental model
- durable execution
- retries and idempotency
- completion notifications

## Build

- job-based AI workflow
- email on job completion
- retry-safe background logic

## Deliverables

- traces or logs showing background execution

## Exit Criteria

- slow AI tasks no longer block the request-response cycle
