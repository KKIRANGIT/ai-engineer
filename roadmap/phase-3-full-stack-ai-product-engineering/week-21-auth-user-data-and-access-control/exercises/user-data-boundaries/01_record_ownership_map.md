# Record Ownership Map

Use the following record types and decide whether they are:

- user-owned
- workspace-owned
- mixed, with a clear primary owner

Records:

- uploaded document
- generated summary
- billing customer profile
- seat invitation
- usage ledger entry
- support ticket comment

For each record, list:

- who can read it
- who can mutate it
- what query filter would prevent accidental leakage
