# Week 21 Exercises

These exercises separate the identity and authorization questions that usually get mixed together.

## Order

1. `identity-and-sessions/`
2. `user-data-boundaries/`
3. `access-review/`

## What To Practice

- defining identity, session, and authorization terms precisely
- mapping user-owned versus workspace-owned records
- spotting where UI protection does not match backend protection

## Done Standard

You are done with the exercise layer when you can explain:

- what the current request knows about the user
- which records belong to a user vs a workspace
- where the product must enforce protection even if the UI is bypassed
