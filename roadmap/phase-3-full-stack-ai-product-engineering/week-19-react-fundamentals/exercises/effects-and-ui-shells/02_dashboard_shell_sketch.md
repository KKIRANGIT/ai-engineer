# Exercise: Dashboard Shell Sketch

## Goal

Design the screen structure before styling every detail.

## Suggested Regions

- header with title and short status summary
- left column for queue controls and ticket list
- center or right column for selected ticket details
- supporting rail for stats and recent activity

## What To Decide

1. Which region should visually dominate?
2. Which actions should stay visible at all times?
3. Where should the "create ticket" flow live?
4. What happens when no ticket is selected?
5. What happens when filters produce zero visible tickets?

## Why This Matters

React fundamentals are not only about logic. They are also about making screen responsibilities obvious.

If the layout is unclear, the component boundaries often become unclear too.
