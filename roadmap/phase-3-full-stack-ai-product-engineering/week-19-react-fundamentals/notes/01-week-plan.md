# Week 19 Plan

Back to [Week 19 README](../README.md)

## Objective

Finish this week with one small but credible React dashboard whose state and component structure you can explain clearly.

## Suggested Flow

### Step 1

Read:

- the Week 19 README
- the exercises README
- the React official pages on components, state, and effects

### Step 2

Do the component and state exercises first.

You should be able to answer:

- which state is shared
- which state stays local
- which values are derived

### Step 3

Read the project README and inspect:

- `src/App.jsx`
- `src/utils.js`
- `src/components/TicketComposer.jsx`
- `src/components/QueueFilters.jsx`

### Step 4

Explain the data flow in writing:

- where tickets live
- how filters update
- how the selected ticket is resolved
- why effects are used

### Step 5

Run the Node tests for the helper functions.

This will not prove the whole UI, but it will confirm the core data logic.

## What Success Looks Like

You are not done because the UI renders.

You are done when you can explain:

- why the state lives where it does
- which parts are reusable
- which values are derived instead of stored
- why the effects are legitimate
