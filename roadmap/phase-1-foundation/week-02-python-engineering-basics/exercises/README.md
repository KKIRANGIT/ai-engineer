# Week 02 Exercises

These exercises are designed to reinforce engineering habits rather than only syntax.

Work through them in this order:

1. `modules/`
2. `validation/`
3. `json/`
4. `type_hints/`
5. `classes/`

How to use them well:

- run each file
- read the comments
- change values and rerun
- break the code on purpose and inspect the error
- rewrite one example in your own words

The goal is not to memorize these files. The goal is to internalize the engineering pattern behind each one.
