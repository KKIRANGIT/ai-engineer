# Week 01: Python Core and Problem Solving

Back to [Phase 1](../README.md)

## Goal

Become fluent enough in Python that syntax stops slowing you down.

## Learn

- variables, collections, control flow
- functions and modules
- basic file I/O
- simple problem-solving patterns

## Build

- 30-50 Python practice problems
- CLI calculator
- CLI todo app with file storage

## Deliverables

- one repo with exercises grouped by topic
- one repo or folder with the CLI apps
- short README with run instructions

## Exit Criteria

- you can solve basic problems without constant syntax lookup
- you can structure code into small functions instead of long scripts
