# CLI Calculator

This project is intentionally small, but it teaches several important beginner skills:

- user input
- converting strings to numbers
- function-based design
- validation
- loops and menus

## Run

```powershell
python calculator.py
```

## What To Study In This Project

- how each operation has its own function
- how invalid input is handled without crashing the whole program
- how the menu loop keeps the program running until the user exits
