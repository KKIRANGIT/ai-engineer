# CLI Todo App

This project is the stronger Week 01 mini-project because it combines:

- lists
- dictionaries
- functions
- file persistence
- menus
- program structure across multiple files

## Run

```powershell
python app.py
```

## File Overview

- `app.py`: user interaction and menu loop
- `todo_logic.py`: task actions such as add, delete, and complete
- `storage.py`: loading and saving JSON data
- `data/tasks.json`: persistent task storage
