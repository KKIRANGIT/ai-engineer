# Python Week 01 Cheat Sheet

## Core Types

- `int`: whole numbers
- `float`: decimal numbers
- `str`: text
- `bool`: `True` or `False`
- `list`: ordered mutable collection
- `tuple`: ordered immutable collection
- `set`: unordered unique values
- `dict`: key-value mapping
- `None`: missing or no value

## Useful Built-ins

- `print()`
- `type()`
- `len()`
- `input()`
- `range()`
- `enumerate()`
- `zip()`

## Condition Pattern

```python
if condition:
    ...
elif another_condition:
    ...
else:
    ...
```

## Loop Pattern

```python
for item in items:
    ...
```

```python
while condition:
    ...
```

## Function Pattern

```python
def function_name(parameter_one, parameter_two):
    result = parameter_one + parameter_two
    return result
```
