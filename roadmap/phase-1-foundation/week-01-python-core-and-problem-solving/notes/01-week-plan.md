# Week 01 Study Plan

## Objective

Become comfortable enough with Python basics that syntax no longer blocks your thinking.

## Recommended Sequence

### Day 1

- run Python in the terminal
- study variables, types, and printing
- complete `exercises/basics/01_variables_and_types.py`

### Day 2

- study truthiness and conditionals
- complete `exercises/basics/02_truthiness_and_conditionals.py`
- change the examples and predict output before running

### Day 3

- study strings and text manipulation
- complete `exercises/strings/01_string_operations.py`

### Day 4

- study lists and dictionaries
- complete `exercises/lists/01_list_operations.py`
- complete `exercises/dicts/01_dictionary_basics.py`

### Day 5

- study loops and functions
- complete `exercises/loops/01_loops_and_patterns.py`
- complete `exercises/functions/01_functions_basics.py`

### Day 6

- build `projects/cli-calculator`
- refactor if any function feels too large

### Day 7

- build `projects/cli-todo-app`
- run the app several times and inspect the JSON file
- write down what confused you

## End-of-Week Checklist

- I can explain the major built-in collection types.
- I can write and call small functions.
- I can use loops and conditions without guessing every line.
- I can read and write simple files.
- I can run both mini-projects from the terminal.
