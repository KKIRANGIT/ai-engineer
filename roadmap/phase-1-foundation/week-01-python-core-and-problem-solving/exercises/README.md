# Week 01 Exercises

These exercises are grouped by topic so you can practice one idea at a time instead of mixing everything together too early.

## How To Use These Files

1. Read the comments at the top of each file.
2. Run the file.
3. Change the values and observe the output.
4. Rewrite one or two examples from memory.
5. Create your own variation below the provided examples.

## Suggested Order

1. `basics/01_variables_and_types.py`
2. `basics/02_truthiness_and_conditionals.py`
3. `strings/01_string_operations.py`
4. `lists/01_list_operations.py`
5. `dicts/01_dictionary_basics.py`
6. `loops/01_loops_and_patterns.py`
7. `functions/01_functions_basics.py`

## Rule

Do not just read these files. Change them, break them, fix them, and explain them in your own words.
