# Week 03: HTTP, APIs, and Integration Thinking

Back to [Phase 1](../README.md)

## Goal

Understand how applications communicate with external services.

## Learn

- request and response model
- methods and status codes
- headers, auth, pagination, rate limits
- JSON request and response handling
- `requests` or `httpx`

## Build

- consume three public APIs
- create a small Python wrapper for one API
- handle auth, retry, pagination, and errors

## Deliverables

- repo with one small SDK-style client
- example scripts for common usage

## Exit Criteria

- you can inspect a failing API call and debug it using status, body, and headers
