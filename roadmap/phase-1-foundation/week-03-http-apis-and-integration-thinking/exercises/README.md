# Week 03 Exercises

These exercises are designed to build API and HTTP intuition before you rely on a larger project.

Work through them in this order:

1. `http-basics/`
2. `json-and-responses/`
3. `query-params/`
4. `resilience/`
5. `wrappers/`

How to use them well:

- run each file
- read the comments carefully
- change example values
- inspect what each helper function is modeling
- explain the output in plain English before moving on

The goal is not only to "call an API." The goal is to understand what integration code is supposed to do.
