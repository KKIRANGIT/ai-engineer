# Git State Lab

## What This Exercise Trains

- working tree awareness
- staging awareness
- commit awareness
- the habit of checking `git status`

## Practice Target

Use:

- [git-practice-sandbox](../../projects/git-practice-sandbox)

## Suggested Flow

1. Open a terminal in the sandbox folder.
2. Run `git init`.
3. Run `git status`.
4. Add one new line to `README.md`.
5. Run `git diff`.
6. Stage only `README.md`.
7. Run `git status` again.
8. Commit with a message like `docs: improve sandbox README`.
9. Run `git log --oneline`.

## What To Notice

- untracked vs modified files
- unstaged vs staged changes
- how status output changes after each step

## Success Check

You should be able to explain:

- what was in the working tree
- what moved into the staging area
- what became part of commit history
