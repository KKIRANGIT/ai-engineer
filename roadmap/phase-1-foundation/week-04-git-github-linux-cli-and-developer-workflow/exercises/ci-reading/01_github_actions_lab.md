# GitHub Actions Reading Lab

## What This Exercise Trains

- reading workflow YAML
- understanding triggers, jobs, and steps
- connecting local commands to CI automation

## Practice Target

Use:

- [python-starter-template](../../projects/python-starter-template)

## Suggested Flow

1. Open `.github/workflows/python-checks.yml`.
2. Identify the trigger events.
3. Identify the operating system runner.
4. Identify each major step.
5. Match the workflow to the local test command in `README.md`.

## Questions To Answer

- when does the workflow run
- what command actually checks the code
- why is this useful before merging

## Success Check

You should be able to explain the workflow in plain English without reading YAML syntax word for word.
