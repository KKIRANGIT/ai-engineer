# Terminal Navigation Lab

## What This Exercise Trains

- moving through directories
- listing files
- reading files
- searching for names and content

## Practice Targets

Use both:

- [git-practice-sandbox](../../projects/git-practice-sandbox)
- [python-starter-template](../../projects/python-starter-template)

## Suggested Tasks

1. Navigate into each project from the terminal.
2. List the top-level files and folders.
3. Find all Python files.
4. Read the project `README.md` from the terminal.
5. Search for the word `greet` inside the starter template.
6. Find the GitHub Actions workflow file.

## Suggested Commands

Linux or Git Bash style:

- `pwd`
- `ls`
- `cd`
- `cat`
- `find`
- `grep`

PowerShell style:

- `Get-Location`
- `Get-ChildItem`
- `Set-Location`
- `Get-Content`
- `Get-ChildItem -Recurse`
- `Select-String`

## Success Check

You should be able to inspect a project structure quickly without relying only on the IDE file tree.
