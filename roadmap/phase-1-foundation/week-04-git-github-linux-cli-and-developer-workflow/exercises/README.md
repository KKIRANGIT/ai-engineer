# Week 04 Exercises

These exercises are designed to reduce operational fear and build repeatable workflow habits.

Work through them in this order:

1. `git-basics/`
2. `branching-and-prs/`
3. `cli-navigation/`
4. `env-and-config/`
5. `ci-reading/`

How to use them well:

- read the exercise slowly
- run the commands yourself
- explain the purpose of each command before executing it
- check repository state often
- use the sandbox project as the safe place to practice

The goal is not to memorize commands. The goal is to understand repository state and workflow decisions.
