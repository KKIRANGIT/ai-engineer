# Terminal and Workflow Cheat Sheet

## Navigation concepts

- current directory
- relative path
- absolute path
- file vs folder

## Common Linux or Git Bash commands

- `pwd`
- `ls`
- `cd`
- `cat`
- `mkdir`
- `mv`
- `cp`
- `find`
- `grep`

## Common PowerShell equivalents

- `Get-Location`
- `Get-ChildItem`
- `Set-Location`
- `Get-Content`
- `New-Item -ItemType Directory`
- `Move-Item`
- `Copy-Item`
- `Get-ChildItem -Recurse`
- `Select-String`

## Workflow habits

- check repo state often
- keep `.env` out of version control
- commit README updates with structure changes
- keep CI simple but real
