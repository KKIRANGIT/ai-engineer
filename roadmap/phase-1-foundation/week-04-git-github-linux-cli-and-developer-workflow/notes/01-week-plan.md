# Week 04 Study Plan

Use this sequence if you want the cleanest execution path.

## Day 1

- read the Git mental-model material
- do `exercises/git-basics/01_git_state_lab.md`
- explain working tree vs staging area in your own words

## Day 2

- read about branches and pull requests
- do `exercises/branching-and-prs/01_branch_workflow_lab.md`
- practice a small feature branch in the sandbox

## Day 3

- do `exercises/cli-navigation/01_terminal_navigation_lab.md`
- inspect both projects mostly from the terminal
- find the workflow file and the tests without using the IDE sidebar

## Day 4

- do `exercises/env-and-config/01_env_gitignore_lab.md`
- inspect `.env.example` and `.gitignore`
- explain what should and should not be committed

## Day 5

- read the SSH and GitHub notes
- map local Git steps to remote GitHub workflow steps
- review the PR checklist

## Day 6

- do `exercises/ci-reading/01_github_actions_lab.md`
- run the local tests and local checks script in the starter template
- explain the GitHub Actions workflow in plain English

## Day 7

- review your command fluency
- write a short note about what now feels routine
- compare your old workflow habits to the starter template workflow
