# Git Practice Sandbox

This folder is a safe local practice area for Git and terminal workflow.

## Purpose

Use this project to practice:

- `git init`
- `git status`
- `git add`
- `git commit`
- `git diff`
- `git switch`
- `git branch`
- simple merge flow

## Important Note

This folder is intentionally lightweight.

It is not meant to be a polished application. It is meant to be a safe place to create, inspect, stage, commit, rename, and reorganize files without risking more important work.

## Suggested Lab Flow

1. initialize a Git repository here
2. inspect the starting files
3. make one docs-only change
4. make one data-only change
5. commit those changes separately
6. create a feature branch
7. make one small change in that branch
8. merge it back

## Files To Practice On

- `app/tasks.py`
