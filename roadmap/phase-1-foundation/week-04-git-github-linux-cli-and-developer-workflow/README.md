# Week 04: Git, GitHub, Linux CLI, and Developer Workflow

Back to [Phase 1](../README.md)

## Goal

Remove tooling friction from daily engineering work.

## Learn

- branching, commits, merges, rebases
- pull requests and issues
- shell navigation and environment variables
- SSH and permissions basics
- simple CI automation

## Build

- create a reusable project template
- open a PR against your own repo
- add CI to run tests automatically

## Deliverables

- at least two repos with passing CI
- one merged PR with meaningful commit history

## Exit Criteria

- Git no longer feels like a blocker
- you can work from the terminal confidently
