# Docker and Pipeline Cheat Sheet

## Basic pipeline stages

- ingest
- validate
- normalize
- enrich
- save
- report

## Docker concepts

- image: the built package of the app and its environment
- container: one running instance of that image
- Dockerfile: the recipe used to build the image

## Why Docker matters

- reproducibility
- fewer machine-specific surprises
- cleaner handoff between environments

## Good beginner rule

If you can explain what each Dockerfile line does, you are learning Docker correctly.
