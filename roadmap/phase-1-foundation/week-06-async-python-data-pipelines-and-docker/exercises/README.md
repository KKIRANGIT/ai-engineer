# Week 06 Exercises

These exercises are designed to build I/O workflow intuition before you rely on the larger pipeline project.

Work through them in this order:

1. `async-basics/`
2. `concurrency/`
3. `csv-processing/`
4. `pipeline-thinking/`
5. `pandas-basics/`
6. `docker-reading/`

How to use them well:

- run the Python exercises
- read the comments carefully
- explain the stage or behavior before changing the code
- compare sync vs async behavior in plain English
- connect each exercise back to the main pipeline project

The goal is not to collect syntax. The goal is to understand workflow shape and runtime behavior.
