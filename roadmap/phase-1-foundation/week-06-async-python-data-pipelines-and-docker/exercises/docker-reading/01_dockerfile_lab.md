# Dockerfile Reading Lab

## What This Exercise Trains

- understanding the purpose of each Dockerfile layer
- mapping local execution to container execution

## Practice Target

Use:

- [event-ingestion-pipeline](../../projects/event-ingestion-pipeline)

## Suggested Flow

1. Open the `Dockerfile`.
2. Identify the base image.
3. Identify the working directory.
4. Identify where project files are copied.
5. Identify the command that runs the application.
6. Explain why `.dockerignore` exists.

## Success Check

You should be able to explain the Dockerfile in plain English without reading it line by line mechanically.
