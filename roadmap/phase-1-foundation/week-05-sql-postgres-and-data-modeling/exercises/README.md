# Week 05 Exercises

These exercises are designed to build relational thinking, not just query memorization.

Work through them in this order:

1. `schema-design/`
2. `select-filtering/`
3. `joins-and-aggregation/`
4. `constraints-and-integrity/`
5. `transactions/`

How to use them well:

- say the data question out loud before reading the SQL
- reason about table shape before writing queries
- inspect which keys connect which tables
- explain why the query result should contain those rows

The goal is not only to write valid SQL. The goal is to understand why the data model makes the query possible.
