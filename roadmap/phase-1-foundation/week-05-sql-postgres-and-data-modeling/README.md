# Week 05: SQL, Postgres, and Data Modeling

Back to [Phase 1](../README.md)

## Goal

Understand relational data design instead of treating the database as a black box.

## Learn

- table design and normalization
- keys and relationships
- joins, grouping, ordering, subqueries
- indexing basics
- Postgres workflows
- Supabase fundamentals

## Build

- solve 25-30 SQL exercises
- design a schema for a real app
- build a CRUD backend against Postgres or Supabase

## Deliverables

- schema diagram
- SQL script folder
- CRUD app demo

## Exit Criteria

- you can justify your schema design
- you can write joins without guessing
