# SQL Query Lab

This folder is the low-friction SQL practice area for Week 05.

## Purpose

Use this project to inspect:

- schema creation
- seed data
- filtering queries
- joins
- aggregation

## Included Files

- `schema.sql`
- `seed.sql`
- `queries.sql`

## How To Use It

You can read these files directly as study material, or load them into SQLite or PostgreSQL if you want to run them manually.

Recommended order:

1. read `schema.sql`
2. read `seed.sql`
3. read each query in `queries.sql`
4. explain what question each query answers
