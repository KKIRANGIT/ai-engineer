# SQL Query Cheat Sheet

## Basic query shape

```sql
SELECT column_one, column_two
FROM some_table
WHERE some_condition
ORDER BY some_column
LIMIT 10;
```

## Useful clauses

- `SELECT`
- `FROM`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `JOIN`
- `LIMIT`

## Useful questions to ask

- what table should I start from
- which rows do I want
- which columns do I need back
- do I need to combine tables
- am I counting rows or reading row details

## Good SQL habit

Write the question in English first, then write the query.
