# Schema and Route Worksheet

Back to [Exercises](../README.md)

Use this worksheet while reading the milestone project.

## Data Model

For each table or entity, answer:

- what does it represent?
- what is its primary key?
- what fields are required?
- what fields are optional?
- what validation rules apply?

## Relationships

For each relationship, answer:

- is it one-to-one, one-to-many, or many-to-many?
- what foreign key represents it?
- what error should happen if the related record does not exist?

## Route Map

For each route, answer:

- what HTTP method is used?
- what is the path?
- what input does it expect?
- what validation does it require?
- what success response does it return?
- what failure responses are reasonable?

## UI Flow Map

Choose one user workflow and map it fully:

1. what the user clicks or submits
2. what request is sent
3. what backend layer handles it
4. what database operation runs
5. what response returns
6. how the UI changes
