# Week 08 Exercises

Back to [Week 08](../README.md)

## Purpose

The exercises for this week are not syntax drills. They are planning and review drills.

That is appropriate for a milestone week because the main skill gap is usually not raw coding. The real gap is often:

- weak scope definition
- fuzzy schema thinking
- unclear API boundaries
- poor demo readiness

These exercises force the thinking that strong milestone projects require.

## Exercise Groups

### `planning/`

Project brief and scope definition.

### `design/`

Schema, routes, and workflow mapping.

### `review/`

Demo readiness, documentation, and quality checks.

## How To Use These Exercises

Recommended order:

1. planning
2. design
3. project build and code study
4. review

You should complete these alongside the project, not after the fact.
