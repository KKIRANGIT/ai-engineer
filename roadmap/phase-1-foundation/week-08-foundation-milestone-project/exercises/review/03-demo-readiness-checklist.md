# Demo Readiness Checklist

Back to [Exercises](../README.md)

Use this before calling the milestone "done."

## Product Understanding

- Can you explain the product in two sentences?
- Can you explain the target user?
- Can you explain why the project was scoped this way?

## Backend Understanding

- Can you explain every API route?
- Can you explain where validation happens?
- Can you explain where database access happens?

## Database Understanding

- Can you explain the schema without looking at the file?
- Can you explain why the relationship design makes sense?

## Frontend Understanding

- Can you explain how the browser loads data?
- Can you explain how forms submit data?
- Can you explain how errors are shown to the user?

## Operational Readiness

- Does the project run locally from the README?
- Do the tests pass?
- Are generated local files ignored appropriately?

## Portfolio Readiness

- Do you have a short architecture summary?
- Can you name at least two tradeoffs?
- Can you name at least two future improvements?
