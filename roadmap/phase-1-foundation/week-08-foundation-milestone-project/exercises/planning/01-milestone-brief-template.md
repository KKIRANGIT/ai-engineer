# Milestone Brief Template

Back to [Exercises](../README.md)

Use this template before you start building or while you are inspecting the included project.

## Product Name

Write the name of the project.

## Target User

Who is this for?

Describe one specific user, not "everyone."

## Core Problem

What small but real problem does this project solve?

## Core Workflow

What is the main path a user follows?

Example format:

1. user creates a subject
2. user logs a study session
3. user reviews progress summary

## Main Entities

List the core entities and what each one stores.

## In Scope

List the features this milestone must include.

## Out Of Scope

List the features you are intentionally not building.

This protects the milestone from uncontrolled growth.

## Technical Choices

State:

- backend language/runtime
- storage choice
- frontend approach
- testing approach

## Success Definition

How will you know the project is complete enough for this week?
