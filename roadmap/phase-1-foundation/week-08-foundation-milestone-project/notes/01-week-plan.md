# Week 08 Study Plan

Back to [Week 08](../README.md)

## Objective

Treat this week like a capstone review, not just another code-reading session.

Your job is to understand how the project combines the earlier skills:

- Python
- routing and APIs
- SQL
- validation
- JavaScript frontend interaction
- documentation discipline

## Suggested Order

### Day 1

- read the Week 08 README
- complete the milestone brief template
- understand why the project scope is intentionally small

### Day 2

- study `sql/schema.sql`
- inspect the repository and service layers
- map the core routes to the database operations they need

### Day 3

- inspect validation and error behavior
- read the tests
- identify what the tests prove and what they do not prove

### Day 4

- inspect the static frontend files
- trace one subject creation flow end to end
- trace one session creation flow end to end

### Day 5

- run the project locally
- create sample data
- verify summary behavior
- delete one session and inspect the result

### Day 6

- read the architecture note
- write your own explanation of the project
- identify two design tradeoffs

### Day 7

- review the portfolio and demo guide
- practice explaining the app as if in an interview or portfolio walkthrough

## Minimum Success Definition

You should not leave this week saying:

"I saw a small full-stack project."

You should leave saying:

"I understand how to build and explain a small full-stack product that combines Phase 1 skills into one coherent system."
