# Week 07: JavaScript, TypeScript, Node.js, and Backend Basics

Back to [Phase 1](../README.md)

## Goal

Become comfortable in the JavaScript and TypeScript ecosystem used by modern AI products.

## Learn

- modern JavaScript syntax
- promises and async patterns
- TypeScript fundamentals
- Node.js runtime basics
- REST API design

## Build

- small Express or Fastify API
- typed version of one earlier utility
- validation for request bodies and errors

## Deliverables

- typed backend repo
- README documenting routes and setup

## Exit Criteria

- you can read and write TypeScript comfortably enough for app work
