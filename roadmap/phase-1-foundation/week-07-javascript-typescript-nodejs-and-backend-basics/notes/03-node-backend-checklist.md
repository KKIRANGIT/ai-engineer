# Node Backend Checklist

Back to [Week 07](../README.md)

Use this checklist when reviewing the reading-list API or any other small Node backend.

## Runtime Understanding

- Can you explain what Node.js is?
- Can you explain the difference between JavaScript, TypeScript, Node.js, and a framework?
- Can you explain why file-system work is asynchronous?

## API Boundary Understanding

- Can you identify the route path?
- Can you identify the HTTP method?
- Can you identify where the request body is parsed?
- Can you identify where validation happens?
- Can you identify where the response shape is chosen?

## Code Structure Understanding

- Can you explain what each file in `src/` is responsible for?
- Can you explain why validation is separate from storage?
- Can you explain why business logic should not live only in the route handler?

## TypeScript Readiness

- Can you describe the shape of a book object?
- Can you explain why a union type is useful?
- Can you explain what an interface communicates?

## Final Self-Test

If you removed one route from the project and rebuilt it yourself, could you do it without blindly copying?

If the answer is no, you need one more pass through the project code.
