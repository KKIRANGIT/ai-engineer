# Week 07 Study Plan

Back to [Week 07](../README.md)

## Objective

Use this week to remove the "second ecosystem" feeling around JavaScript and Node.

The most important outcome is not stylistic confidence. It is operational confidence:

- you can read the code
- you can explain the runtime flow
- you can modify the project without panic

## Suggested Order

### Day 1

- read the Week 07 README
- complete the JavaScript basics exercises
- compare arrays and objects with Python lists and dictionaries

### Day 2

- complete the async and Node exercises
- explain promises, `async`, and `await` in your own words
- inspect how file reads become promise-based work

### Day 3

- complete the TypeScript exercises
- write two extra typed functions of your own
- compare the same logic in JavaScript and TypeScript

### Day 4

- complete backend-thinking and validation exercises
- sketch the flow of `POST /books` before reading the project code deeply

### Day 5

- read the main project `README.md`
- inspect `src/` one file at a time
- trace a request from `server.js` to final response

### Day 6

- run the API locally
- create one book
- fetch all books
- mark one book as read
- inspect the JSON file persistence

### Day 7

- read the Python-vs-JavaScript notes
- review the TypeScript reference folder
- write your own summary of what is still confusing

## Minimum Success Definition

You should not leave this week saying:

"I copied a Node project."

You should leave saying:

"I understand how a small Node API is put together, how JavaScript differs from Python, and how TypeScript improves the contract layer."
