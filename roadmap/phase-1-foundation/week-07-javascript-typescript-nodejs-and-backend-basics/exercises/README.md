# Week 07 Exercises

Back to [Week 07](../README.md)

## Purpose

These exercises are designed to remove the first layer of confusion that many Python-first learners experience when they enter the JavaScript and TypeScript ecosystem.

The goal is not to build large programs here. The goal is to make the syntax, runtime habits, and type vocabulary feel normal enough that the project work becomes readable.

## Exercise Groups

### `javascript-basics/`

Core value types, arrays, objects, functions, modules, and common collection operations.

### `async-and-node/`

Promise-based thinking, `async` / `await`, and simple file-system work in Node.

### `typescript-basics/`

Type annotations, object shapes, union types, and basic narrowing.

### `backend-thinking/`

HTTP route flow, request interpretation, response shaping, and status-code choices.

### `validation-and-errors/`

Input checks, predictable failures, and simple error messages that help both the developer and the caller.

## How To Use These Exercises

Recommended order:

1. JavaScript basics
2. Async and Node
3. TypeScript basics
4. Backend thinking
5. Validation and errors

For each file:

1. read the top docstring
2. run the file
3. inspect the printed output
4. change values and re-run it
5. explain what changed and why

The learning goal is not passive recognition. It is active control.
